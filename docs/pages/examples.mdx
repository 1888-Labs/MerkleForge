# Examples

<LangBar always />

<Rust>

Complete programs you can paste into `src/main.rs`. Each one compiles against the current
crates; add the dependencies first:

```toml [Cargo.toml]
[dependencies]
merkle-core = "0.5.1"
merkleforge-hash = "0.5.1"
merkle-variants = "0.5.1"
```

:::note
Examples that use `BinaryMerkleTree::from_leaves` or tree serialization need v0.5.0 or later.
Everything else also works with v0.4.x.
:::

</Rust>

<TypeScript>

Complete programs you can paste into `index.ts` and run with `npx tsx index.ts` (or `node index.ts`
on Node.js 23.6+). Install the packages first:

```bash
npm i @merkleforge/core @merkleforge/hash @merkleforge/variants
```

## Binary inclusion proof

Build a tree, prove one leaf, and verify it with only the root, the proof, and the leaf bytes.
[Guide](/docs/guides/binary-merkle-tree)

<Rust>

```rust [src/main.rs]
use merkle_core::types::LeafIndex;
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::Sha256;

fn main() -> Result<(), merkle_core::error::MerkleError> {
    let mut tree = BinaryMerkleTree::<Sha256>::new();
    tree.insert(b"alice:100")?;
    tree.insert(b"bob:250")?;

    let proof = tree.generate_proof(LeafIndex(0))?;
    let root = tree.root().expect("tree is not empty");

    assert!(BinaryMerkleTree::<Sha256>::verify(
        root,
        b"alice:100",
        &proof,
    ));
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'

const tree = new BinaryMerkleTree(Sha256)
tree.insert(utf8('alice:100'))
tree.insert(utf8('bob:250'))

const proof = tree.generateProof(0)
const root = tree.root()!

console.assert(BinaryMerkleTree.verify(Sha256, root, utf8('alice:100'), proof))
```

</TypeScript>

## Sparse account state

Commit balances under 32-byte keys and prove one account's value.
[Guide](/docs/guides/sparse-merkle-tree)

<Rust>

```rust [src/main.rs]
use merkle_variants::SparseMerkleTree;
use merkleforge_hash::Sha256;

fn main() -> Result<(), merkle_core::error::MerkleError> {
    let mut state = SparseMerkleTree::<Sha256>::new();
    let alice = [7_u8; 32];
    let bob = [9_u8; 32];

    state.insert(alice, b"balance:100")?;
    state.insert(bob, b"balance:250")?;

    let proof = state.generate_membership_proof(alice)?;
    let root = state.root().expect("state is not empty");

    assert!(SparseMerkleTree::<Sha256>::verify_membership(
        root,
        alice,
        b"balance:100",
        &proof,
    ));

    // Prove that a key is absent.
    let carol = [11_u8; 32];
    let absent = state.generate_membership_proof(carol)?;
    assert!(SparseMerkleTree::<Sha256>::verify_non_membership(root, carol, &absent));
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { SparseMerkleTree } from '@merkleforge/variants'

const state = new SparseMerkleTree(Sha256)
const alice = new Uint8Array(32).fill(7)
const bob = new Uint8Array(32).fill(9)

state.insert(alice, utf8('balance:100'))
state.insert(bob, utf8('balance:250'))

const proof = state.generateMembershipProof(alice)
const root = state.root()!

console.assert(SparseMerkleTree.verifyMembership(Sha256, root, alice, utf8('balance:100'), proof))

// Prove that a key is absent.
const carol = new Uint8Array(32).fill(11)
const absent = state.generateMembershipProof(carol)
console.assert(SparseMerkleTree.verifyNonMembership(Sha256, root, carol, absent))
```

</TypeScript>

## Patricia witness

Ethereum-style key-value state with an RLP witness. [Guide](/docs/guides/merkle-patricia-trie)

<Rust>

```rust [src/main.rs]
use merkle_variants::MerklePatriciaTrie;
use merkleforge_hash::Keccak256;

fn main() -> Result<(), merkle_core::error::MerkleError> {
    let mut trie = MerklePatriciaTrie::<Keccak256>::new();

    trie.insert(b"account:alice", b"100")?;
    trie.insert(b"account:bob", b"250")?;

    let proof = trie.generate_proof(b"account:alice")?;
    let root = trie.root().expect("trie is not empty");

    assert_eq!(proof.key, b"account:alice");
    assert_eq!(proof.value.as_deref(), Some(b"100".as_slice()));
    println!("witness has {} RLP nodes", proof.proof_nodes.len());
    assert!(MerklePatriciaTrie::<Keccak256>::verify_proof(root, &proof));
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { bytesEqual, utf8 } from '@merkleforge/core'
import { Keccak256 } from '@merkleforge/hash'
import { MerklePatriciaTrie } from '@merkleforge/variants'

const trie = new MerklePatriciaTrie(Keccak256)

trie.insert(utf8('account:alice'), utf8('100'))
trie.insert(utf8('account:bob'), utf8('250'))

const proof = trie.generateProof(utf8('account:alice'))
const root = trie.root()!

console.assert(bytesEqual(proof.key, utf8('account:alice')))
console.assert(proof.value !== null && bytesEqual(proof.value, utf8('100')))
console.log(`witness has ${proof.proofNodes.length} RLP nodes`)
console.assert(MerklePatriciaTrie.verifyProof(Keccak256, root, proof))
```

</TypeScript>

## Swap the hash function

The same tree API over three algorithms. [Guide](/docs/guides/hash-functions)

<Rust>

```rust [src/main.rs]
use merkle_core::traits::MerkleTree;
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::{Blake3, Keccak256, Sha256};

fn main() -> Result<(), merkle_core::error::MerkleError> {
    let mut sha_tree = BinaryMerkleTree::<Sha256>::new();
    let mut eth_tree = BinaryMerkleTree::<Keccak256>::new();
    let mut fast_tree = BinaryMerkleTree::<Blake3>::new();

    for leaf in [b"alice".as_slice(), b"bob", b"carol"] {
        sha_tree.insert(leaf)?;
        eth_tree.insert(leaf)?;
        fast_tree.insert(leaf)?;
    }

    for meta in [sha_tree.metadata(), eth_tree.metadata(), fast_tree.metadata()] {
        println!("{}: {} leaves, height {}", meta.hash_algorithm, meta.leaf_count, meta.height);
    }
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { utf8 } from '@merkleforge/core'
import { Blake3, Keccak256, Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'

const trees = [Sha256, Keccak256, Blake3].map((hasher) => new BinaryMerkleTree(hasher))

for (const leaf of ['alice', 'bob', 'carol']) {
  for (const tree of trees) tree.insert(utf8(leaf))
}

for (const tree of trees) {
  const meta = tree.metadata()
  console.log(`${meta.hashAlgorithm}: ${meta.leafCount} leaves, height ${meta.height}`)
}
```

</TypeScript>

## Hash directly

Use an adapter without a tree: leaf hashes, parent hashes, and metadata.

<Rust>

```rust [src/main.rs]
use merkle_core::traits::HashFunction;
use merkleforge_hash::Blake3;

fn main() {
    let left = Blake3::hash(b"left leaf");
    let right = Blake3::hash(b"right leaf");
    let parent = Blake3::hash_nodes(&left, &right);

    assert_ne!(parent, left);
    assert_eq!(Blake3::digest_size(), 32);
    assert_eq!(Blake3::algorithm_name(), "BLAKE3");
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { bytesEqual, utf8 } from '@merkleforge/core'
import { Blake3 } from '@merkleforge/hash'

const left = Blake3.hash(utf8('left leaf'))
const right = Blake3.hash(utf8('right leaf'))
const parent = Blake3.hashNodes(left, right)

console.assert(!bytesEqual(parent, left))
console.assert(Blake3.digestSize === 32)
console.assert(Blake3.algorithmName === 'BLAKE3')
```

</TypeScript>

## Tree metadata

Inspect a tree for logs and dashboards. [Guide](/docs/guides/metadata)

<Rust>

```rust [src/main.rs]
use merkle_core::traits::MerkleTree;
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::Sha256;

fn main() -> Result<(), merkle_core::error::MerkleError> {
    let tree = BinaryMerkleTree::<Sha256>::from_leaves(["alice", "bob", "carol"])?;

    let metadata = tree.metadata();
    println!("variant: {}", metadata.variant);
    println!("algorithm: {}", metadata.hash_algorithm);
    println!("leaves: {}", metadata.leaf_count);
    println!("height: {}", metadata.height);
    println!("allocated nodes: {}", metadata.node_count);
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'

const tree = BinaryMerkleTree.fromLeaves(Sha256, ['alice', 'bob', 'carol'].map(utf8))

const metadata = tree.metadata()
console.log('variant:', metadata.variant)
console.log('algorithm:', metadata.hashAlgorithm)
console.log('leaves:', metadata.leafCount)
console.log('height:', metadata.height)
console.log('allocated nodes:', metadata.nodeCount)
```

</TypeScript>

## Proof transport

Serialize a proof to bytes on the server and decode it on the client.
[Guide](/docs/guides/serialization)

<Rust>

```rust [src/main.rs]
use merkle_core::{
    traits::Serializable,
    types::{LeafIndex, MerkleProof},
};
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::Sha256;

fn main() -> Result<(), merkle_core::error::MerkleError> {
    // Server
    let tree = BinaryMerkleTree::<Sha256>::from_leaves(["tx1", "tx2", "tx3"])?;
    let root = *tree.root().expect("tree is not empty");
    let bytes = tree.generate_proof(LeafIndex(1))?.to_bytes()?;

    // ... send `root` (trusted channel) and `bytes` (any channel) ...

    // Client
    let proof = MerkleProof::<[u8; 32]>::from_bytes(&bytes)?;
    assert!(BinaryMerkleTree::<Sha256>::verify(&root, b"tx2", &proof));
    Ok(())
}
```

</Rust>

<TypeScript>

```ts [index.ts]
import { decodeMerkleProof, encodeMerkleProof, utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'

// Server
const tree = BinaryMerkleTree.fromLeaves(Sha256, ['tx1', 'tx2', 'tx3'].map(utf8))
const root = tree.root()!
const bytes = encodeMerkleProof(tree.generateProof(1))

// ... send `root` (trusted channel) and `bytes` (any channel) ...

// Client
const proof = decodeMerkleProof(bytes)
console.assert(BinaryMerkleTree.verify(Sha256, root, utf8('tx2'), proof))
```

</TypeScript>

## Stateless light client

The tree is dropped before verification; only the root and the proof reach the client.

<Rust>

```rust [merkle-variants/examples/light_client.rs]
use merkle_core::{error::MerkleError, types::LeafIndex};
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::Sha256;

fn main() -> Result<(), MerkleError> {
    let proof;
    let root;

    {
        let mut tree = BinaryMerkleTree::<Sha256>::new();
        tree.insert(b"tx:alice->bob:100")?;
        tree.insert(b"tx:bob->carol:50")?;
        tree.insert(b"tx:carol->dave:25")?;

        root = *tree.root().expect("tree has inserted leaves");
        proof = tree.generate_proof(LeafIndex(0))?;

        println!("server: built tree and exported root + proof");
    }

    let valid = BinaryMerkleTree::<Sha256>::verify(&root, b"tx:alice->bob:100", &proof);

    println!("client: tree dropped before verification");
    println!("Stateless verification: {valid}");

    Ok(())
}
```

```bash
cargo run -p merkle-variants --example light_client
```

</Rust>

<TypeScript>

The tree only lives inside `server()`; the client verifies with the root and proof alone.

```ts [index.ts]
import { type Bytes, type MerkleProof, utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'

function server(): { root: Bytes; proof: MerkleProof } {
  const tree = new BinaryMerkleTree(Sha256)
  tree.insert(utf8('tx:alice->bob:100'))
  tree.insert(utf8('tx:bob->carol:50'))
  tree.insert(utf8('tx:carol->dave:25'))

  console.log('server: built tree and exported root + proof')
  return { root: tree.root()!, proof: tree.generateProof(0) }
}

// The tree goes out of scope when `server` returns; only the root and proof leave it.
const { root, proof } = server()

const valid = BinaryMerkleTree.verify(Sha256, root, utf8('tx:alice->bob:100'), proof)

console.log('client: tree dropped before verification')
console.log(`Stateless verification: ${valid}`)
```

</TypeScript>
