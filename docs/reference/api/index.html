Core

merkle-core: traits, types, and errors shared by every crate. no_std + alloc capable (details).

merkle_core::prelude re-exports MerkleError, HashFunction, MerkleTree, ProofVerifier, Serializable, LeafIndex, MerkleProof, NodeIndex, ProofNode, ProofSide, and TreeMetadata.

use merkle_core::prelude::*;
 
fn main() {
    let index = LeafIndex(3);
    assert_eq!(index.value(), 3);
    assert_eq!(NodeIndex::from(index), NodeIndex(3));
    assert_eq!(NodeIndex::root(4), NodeIndex(6)); // [L0 L1 L2 L3 P01 P23 Root]
}

@merkleforge/core: interfaces, proof types, errors, and helpers shared by every package. It has no runtime dependencies.

import { isMerkleError, isTrivialProof, MerkleError, proofDepth, utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'
 
const tree = BinaryMerkleTree.fromLeaves(Sha256, ['a', 'b', 'c', 'd'].map(utf8))
const proof = tree.generateProof(3)
 
console.assert(proof.leafIndex === 3 && proof.leafCount === 4)
console.assert(proofDepth(proof) === 2 && !isTrivialProof(proof))
console.assert(tree.leafCount === 4 && tree.height === 3)
 
try {
  tree.generateProof(9)
} catch (error) {
  console.assert(isMerkleError(error, 'IndexOutOfBounds') && error instanceof MerkleError)
}

Errors

MerkleError, a #[non_exhaustive] enum. See Errors.

MerkleError extends Error. Its code (and detail) is one of EmptyTree, IndexOutOfBounds, InvalidProof, InvalidProofStructure, EmptyLeafData, SerializationError, DeserializationError, HashError, UnsupportedOperation, or RlpError. isMerkleError(error, code?) narrows an unknown error. See Errors.

All three are zero-sized, Copy, and produce [u8; 32]. See Hash functions.

@merkleforge/hash (built on @noble/hashes):

ItemDescription
Sha256SHA-256 with 0x00/0x01 domain prefixes

Each is a frozen HashFunction object producing 32-byte digests, identical to the Rust adapters. Pass it to a tree's constructor and to the static verifiers.

@merkleforge/hash-wasm adds createKeccak256Wasm() and createSha256Wasm(), async factories for WebAssembly versions with the same output and algorithmName (about 6x faster Keccak-256 in Node). See Hash functions.

Trees

merkle-variants. Top-level re-exports: BinaryMerkleTree, SparseMerkleTree, MerklePatriciaTrie, MptProof.

@merkleforge/variants. Every tree takes its HashFunction in the constructor; verifiers are static and take the hash function first. Trees serialize with toJSON() and load with fromJSON(hasher, json), which rejects JSON written with a different hash.

Proof formats

Every proof type implements Serialize, Deserialize, and Serializable (bincode). See Serialization.

Each proof type has a bincode codec and a serde_json-compatible JSON codec, with the same bytes and JSON as the Rust crates:

ProofBincodeJSON
MerkleProofencodeMerkleProof / decodeMerkleProofmerkleProofToSerdeJSON / merkleProofFromSerdeJSON
BinaryMultiProofencodeBinaryMultiProof / decodeBinaryMultiProofmultiProofToSerdeJSON / multiProofFromSerdeJSON
SparseMerkleProofencodeSparseProof / decodeSparseProofsparseProofToSerdeJSON / sparseProofFromSerdeJSON
MptProofencodeMptProof / decodeMptProofmptProofToSerdeJSON / mptProofFromSerdeJSON

For the Solidity verifiers, toSolidityBinaryProof, toSolidityBinaryMultiProof, and toSoliditySparseProof reshape proofs into hex strings (and a bigint bitmap for sparse proofs). See Serialization and Proofs.

Safety

Every published crate uses #![forbid(unsafe_code)] and #![deny(missing_docs)].

The packages compile with strict, noUncheckedIndexedAccess, and exactOptionalPropertyTypes, document every public API with TSDoc (including what it throws), and return copies of internal Uint8Array state rather than the buffers themselves. The tree verifiers (verify, verifyMultiProof, verifyMembership, verifyNonMembership, verifyProof) return false for malformed proofs instead of throwing; proveValue and the @merkleforge/ethereum functions throw InvalidProof, because they return the proven value. Releases are published with provenance through npm trusted publishing.
