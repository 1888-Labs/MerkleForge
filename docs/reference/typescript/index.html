TypeScript packages

MerkleForge for TypeScript and JavaScript is published on npm under the @merkleforge scope. It implements the same trees, hashes, and proof formats as the Rust crates, with an idiomatic TypeScript API. The source lives in 1888-Labs/MerkleForge-ts.

  • Runtimes: Node.js 22+, browsers, Deno, and Bun. ESM only.
  • Dependencies: the only runtime dependency is @noble/hashes.
  • Compatibility: roots and proofs match the Rust crates byte for byte. A proof generated by a Rust server verifies in a browser, and the other way round. This is tested against vectors generated by the Rust crates.

The repository also contains Solidity verifiers for every Keccak-256 proof type (MerkleForgeBinary, MerkleForgeSparse, MerkleForgePatricia, MerkleForgeEthereum); see contracts/.

npm i @merkleforge/core @merkleforge/hash @merkleforge/variants

Staging builds from the develop branch are published under the next dist-tag (npm i @merkleforge/variants@next).

Releases are published from CI through npm trusted publishing with provenance, and a maintainer approves each version with 2FA before it goes live.

Versioning

The npm packages are versioned independently of the Rust crates (for example npm 0.2.1 alongside crates 0.5.1). Compatibility is defined by the formats, not the version numbers: the hashing scheme, proof structure, and the bincode and JSON proof encodings are shared, and the TypeScript test suite checks them in CI against vectors generated by the Rust crates. Release notes are on GitHub Releases.
