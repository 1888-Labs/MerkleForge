Authenticated data structures for Rust and TypeScript

Binary, Sparse, and Ethereum-compatible Patricia Merkle trees behind one API, with pluggable hash functions and stateless proof verification. Rust crates and TypeScript packages produce byte-identical roots and proofs: prove on a Rust server, verify in the browser.

One API, three trees
Binary, Sparse, and Patricia trees share one MerkleTree interface, in both languages. Choose a tree
Pluggable hashes
Swap SHA-256, Keccak-256, and BLAKE3 without touching the rest of your code. In Rust it is one type parameter that compiles away.
Stateless proofs
Verify a leaf with only the trusted root, the proof, and the leaf bytes. No tree required.
Ethereum-compatible
The Patricia trie with Keccak-256 matches Ethereum state roots and passes the official trie test vectors.

Rust crates
merkle-core, merkleforge-hash, and merkle-variants on crates.io. The reference implementation: zero unsafe, no_std support in merkle-core, and Criterion benchmarks. crates.io · docs.rs
TypeScript packages
@merkleforge/core, hash, and variants on npm, with an idiomatic API for Node.js, browsers, Deno, and Bun. Published with provenance through npm trusted publishing. Packages and API mapping

Roots, proofs, and the bincode and JSON proof encodings are byte-identical between the two, checked in CI against vectors generated by the Rust crates. Every guide shows both: use the Rust / TypeScript switch.

Example
Build a root, prove a leaf, verify anywhere

Insert raw bytes, get a 32-byte root, and hand a light client an O(log n) proof. The verifier never sees the rest of the data, and it can run in either language.

More examplesTry the live demo
src/main.rs
use merkle_core::prelude::*;
use merkle_variants::BinaryMerkleTree;
use merkleforge_hash::Sha256;
 
fn main() -> Result<(), MerkleError> {
    let tree = BinaryMerkleTree::<Sha256>::from_leaves([
        "alice:100", "bob:250", "carol:75",
    ])?;
 
    let root = tree.root().expect("tree is non-empty");
    let proof = tree.generate_proof(LeafIndex(1))?;
 
    // Stateless: only the root, the leaf bytes, and the proof.
    assert!(BinaryMerkleTree::<Sha256>::verify(root, b"bob:250", &proof));
    Ok(())
}
index.ts
import { utf8 } from '@merkleforge/core'
import { Sha256 } from '@merkleforge/hash'
import { BinaryMerkleTree } from '@merkleforge/variants'
 
const tree = BinaryMerkleTree.fromLeaves(Sha256, ['alice:100', 'bob:250', 'carol:75'].map(utf8))
 
const root = tree.root()!
const proof = tree.generateProof(1)
 
// Stateless: only the root, the leaf bytes, and the proof.
console.assert(BinaryMerkleTree.verify(Sha256, root, utf8('bob:250'), proof))
