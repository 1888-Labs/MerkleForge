# Changelog

The Rust crates and the TypeScript packages are released separately and versioned independently.
Compatibility comes from the shared proof formats, not from matching version numbers. Both follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Rust crates

The full changelog lives in the repository:
**[CHANGELOG.md on GitHub](https://github.com/1888-Labs/MerkleForge/blob/main/CHANGELOG.md)**.

`merkle-core`, `merkleforge-hash`, and `merkle-variants` are versioned together; one entry covers
all published crates. `merkle-bench` is never published. The changelog follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

### v0.5.1 (2026-10-20)

* **Added:** `BinaryMerkleTree::generate_multi_proof` and `verify_multi_proof`, with the new
  `BinaryMultiProof` type: one proof for several leaves, sharing sibling hashes. Its serde and
  bincode format matches the TypeScript package
  [`@merkleforge/variants`](https://www.npmjs.com/package/@merkleforge/variants), so multiproofs
  move between Rust and TypeScript unchanged.

### v0.5.0 (2026-10-14)

Correctness and performance fixes. Roots and proofs for the shipped hash adapters are unchanged.

* **Added:** `BinaryMerkleTree::from_leaves` (one-pass `O(n)` build),
  `SparseMerkleTree::verify_membership` (checks the proof's key),
  `HashFunction::hash_encoded_node`, `NodeEntry::commitment`, and `Clone` / `Debug` / `Serialize` /
  `Deserialize` for all three trees.
* **Fixed:** sparse and Patricia inserts and removals recompute only the changed path (4,000
  sparse inserts: about 223 s to 0.2 s; one sparse proof: 151 ms to 25 µs; 4,000 Patricia inserts:
  about 5.9 s to 0.02 s). `MerkleTree::insert` on sparse and Patricia trees no longer overwrites a
  leaf after a removal.
* **Breaking:** the default `HashFunction::hash_nodes` now hashes `0x01 ‖ left ‖ right`;
  `MerklePatriciaTrie` selects plain Keccak through `hash_encoded_node` instead of the algorithm
  name; the hidden `MptNode::__DigestMarker` variant is gone.
* **Deprecated:** `SparseMerkleTree::verify`. Use `verify_membership`.
* **Docs:** this Vocs documentation site replaces the old React website, and the repository moved
  to `1888-Labs/MerkleForge`.

### v0.4.1 (2026-09-05)

Packaging and documentation refresh for the MerkleForge Framework rebrand: crate metadata,
rewritten crate READMEs, and `CONTRIBUTING.md`.

### v0.4.0 (2026-07-27)

Adds the Ethereum-compatible `MerklePatriciaTrie<H>` with RLP and hex-prefix encoding,
EIP-1186-style `MptProof` witnesses, and validation against official Ethereum trie vectors.

## TypeScript packages

Release notes for each version are on
**[GitHub Releases](https://github.com/1888-Labs/MerkleForge-ts/releases)**, and each package has a
`CHANGELOG.md` generated by [Changesets](https://github.com/changesets/changesets).

All six `@merkleforge/*` packages are versioned together. Versions up to 0.1.1 were published as
`@1888-labs/merkle-*`, which are now deprecated. `next` snapshots from the `develop` branch are not
listed here.

### v0.2.2 (2026-10-27)

* **Changed:** releases are published from CI through npm trusted publishing (OIDC) with
  provenance, and a maintainer approves each version with 2FA before it goes live. There is no
  long-lived npm token.

### v0.2.1 (2026-10-20)

* **Added:** [`@merkleforge/openzeppelin`](https://www.npmjs.com/package/@merkleforge/openzeppelin),
  a drop-in replacement for `@openzeppelin/merkle-tree`. `StandardMerkleTree` and
  `SimpleMerkleTree` produce identical roots, proofs, multiproofs, and `dump()` JSON, so proofs
  verify with OpenZeppelin's `MerkleProof` on-chain and existing dumps load unchanged. Includes a
  dependency-free `abiEncode`.

### v0.2.0 (2026-10-18)

* **Changed:** the packages moved to the `@merkleforge` scope: `@1888-labs/merkle-core` is now
  `@merkleforge/core`, and likewise `hash`, `hash-wasm`, `variants`, and `ethereum`. The API is
  unchanged; update your imports. The `@1888-labs/merkle-*` packages are deprecated.

### v0.1.1 (2026-10-18)

* **Changed:** rewritten package READMEs with API tables and more examples.

### v0.1.0 (2026-10-18)

Initial TypeScript release, as `@1888-labs/merkle-*`.

* `BinaryMerkleTree`, `SparseMerkleTree`, and an Ethereum-compatible `MerklePatriciaTrie`, with
  roots and proofs that match the Rust crates.
* SHA-256, Keccak-256, and BLAKE3 adapters, plus WebAssembly Keccak-256 and SHA-256 in
  `hash-wasm`.
* Binary multiproofs.
* Proof codecs that are byte-compatible with Rust's bincode and `serde_json` output.
* Helpers that shape proofs for the MerkleForge Solidity verifiers.
* `eth_getProof` account and storage proof verification in `ethereum`.
