Demos

Each demo models a real system and runs the published @merkleforge/* TypeScript packages in your browser. Nothing you type or pick is uploaded; the only network request is the optional live fetch on the Ethereum page, and only when you click it. Roots and proofs match the Rust crates byte for byte.

Performance

BinaryMerkleTree · 5 hash adapters
In-browser benchmarks

Build trees of up to 131,072 leaves on your own device with Keccak-256, SHA-256 (pure JS and WebAssembly), and BLAKE3, and compare build, proof, and verify times.

Blockchain

@merkleforge/openzeppelin · Solidity
Airdrop claim

Publish a token allocation as one root, generate a claim proof that OpenZeppelin's MerkleProof accepts on-chain, and watch an inflated claim fail.

@merkleforge/ethereum · Patricia trie
Ethereum state proof

Verify a real mainnet eth_getProof response for WETH against a block's state root, catch a lying RPC, or fetch a live proof.

Beyond blockchain

BinaryMerkleTree · SHA-256 WASM
File integrity

Commit to a file in 64 KiB chunks, as BitTorrent v2 and IPFS do, then verify each chunk on its own and pinpoint a corrupted one.

SparseMerkleTree · Keccak-256
Revocation list

Keep revoked certificates, DIDs, or API keys in a sparse Merkle tree and prove that an ID is revoked, or that it is not.

BinaryMerkleTree · SHA-256
Light client

A server commits rows to a root and sends one row with its proof; a client that holds only the root accepts it or detects tampering.
